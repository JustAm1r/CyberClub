# CyberClub

## О проекте

CyberClub — информационная система для бронирования и управления компьютерным клубом.

Система позволит клиентам:
- просматривать свободные компьютеры;
- выбирать дату и время;
- бронировать компьютер;
- выбирать тариф;
- просматривать свои бронирования.

Администратор компьютерного клуба сможет:
- просматривать все бронирования;
- управлять компьютерами;
- менять статус компьютера;
- управлять тарифами;
- контролировать занятость компьютеров.

## Статусы компьютеров

- Свободен
- Забронирован
- Занят
- На ремонте

## Цель проекта

Упростить процесс бронирования компьютеров в компьютерном клубе и уменьшить объём ручной работы администратора.

## Пользователи системы

1. Клиент компьютерного клуба
2. Администратор компьютерного клуба

## Основные функции

- Регистрация и авторизация
- Просмотр списка компьютеров
- Просмотр свободного времени
- Бронирование компьютера
- Отмена бронирования
- Выбор тарифа
- Управление бронированиями
- Управление статусами компьютеров
