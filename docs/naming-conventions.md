# Правила именования задач и веток проекта CyberClub

## 1. Именование задач

Название задачи должно начинаться с действия и кратко описывать результат.

Примеры:

- Создать страницу регистрации пользователя
- Реализовать авторизацию
- Добавить бронирование компьютера
- Исправить ошибку отмены бронирования
- Обновить документацию проекта

## 2. Типы задач

В проекте используются следующие типы:

- Feature — новая функция
- Bug — исправление ошибки
- Documentation — работа с документацией
- Improvement — улучшение существующей функции

## 3. Приоритет задач

Используются три уровня:

- High — важная задача, влияющая на основные функции системы
- Medium — задача средней важности
- Low — второстепенная задача

## 4. Оценка задач

Для приблизительной оценки сложности используются значения:

- 1 — очень простая задача
- 2 — простая
- 3 — средняя
- 5 — сложная
- 8 — очень сложная

## 5. Именование веток

Формат:

тип/номер-задачи-краткое-название

Примеры:

feature/1-user-registration
feature/2-authentication
feature/3-computer-list
bug/10-booking-error
docs/5-update-readme

## 6. Основная ветка

Основная ветка проекта:

main

Изменения должны попадать в main после завершения и проверки задачи.
