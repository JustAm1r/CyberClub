# Лабораторная работа №3

## Проект: CyberClub

CyberClub — информационная система бронирования и управления компьютерным клубом.

В лабораторной работе №3 выполнены:

1. Бизнес-кейс проекта
2. Финансовая модель TCO на 3 года
3. Расчёт ROI и срока окупаемости
4. Сравнение открытого и проприетарного варианта
5. Анализ чувствительности
6. Устав проекта

## Основные результаты

### Выбранное решение

Для проекта выбран вариант собственной разработки CyberClub как учебного проекта.

### TCO

TCO открытого варианта за 3 года:

**15 000 ₸**

### ROI

Расчётный ROI:

**7 580%**

### Срок окупаемости

При принятых учебных допущениях:

**около 5 дней**

### Анализ чувствительности

Проект остаётся экономически положительным при:

- увеличении затрат на 30%;
- достижении только 50% ожидаемого эффекта.

## Важное примечание

Финансовые и операционные показатели проекта являются учебными допущениями.

При реальном внедрении значения должны быть подтверждены данными конкретного компьютерного клуба.
