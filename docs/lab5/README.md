# Зертханалық жұмыс №5

## Жоба: CyberClub

CyberClub — компьютерлік клубтағы компьютерлерді брондау және басқаруға арналған ақпараттық жүйе.

Лабораториялық жұмыстың мақсаты — жобаны жоспарлау, жұмысты WBS арқылы декомпозициялау, релиздерді анықтау, тәуелділіктерді көрсету, жауапкершілікті бөлу және нақты capacity есептеу.

# 2. 100% ережесін тексеру

WBS құрылымы 100% ережесіне сәйкес құрастырылды: әр ата-аналық элементтің барлық еншілес элементтері бірігіп, сол бөлімнің толық көлемін жабады.

| Ата-аналық элемент | Еншілес элементтер | Неге 100% жабады |
|---|---|---|
| 1.1 Талаптар және жобалық негіз | Функционалдық талаптар, ФЕТ, архитектура | Жобаны бастауға қажетті талаптар мен техникалық негіз толық қамтылған |
| 1.2 Пайдаланушы аккаунттары | Тіркелу, авторизация, рөлдер | Пайдаланушы аккаунтымен жұмыс істеудің негізгі циклі толық қамтылған |
| 1.3 Компьютерлер каталогы | Тізім, мәртебе, қолжетімді уақыт | Компьютерді таңдау үшін қажетті негізгі ақпарат толық көрсетіледі |
| 1.4 Брондау модулі | Күн/уақыт, брондау, бас тарту | Брондау сценарийі басынан соңына дейін толық қамтылады |
| 1.5 Тарифтер | Тізім, таңдау, басқару | Тарифпен жұмыс істеудің негізгі функциялары толық қамтылған |
| 1.6 Жеке кабинет | Брондаулар, мәртебе, басқару | Клиенттің өз брондауларын бақылауы толық қамтылған |
| 1.7 Әкімшілік панель | Брондаулар, ПК мәртебелері, тарифтер | Әкімшінің негізгі басқару функциялары толық қамтылған |
| 1.8 Сапа және тестілеу | Функционалдық тест, ФЕТ, UAT | Жүйе сапасын тексерудің негізгі түрлері толық қамтылған |
| 1.9 Релиз және құжаттама | Нұсқаулық, орнату, релиз | Жүйені тапсыру және іске қосуға қажетті нәтижелер толық қамтылған |

---

## Қорытынды

CyberClub жобасы WBS арқылы 3 деңгейге дейін декомпозицияланды. Жобаның негізгі функционалдық, техникалық және релиздік нәтижелері толық қамтылды. WBS 100% ережесіне сәйкес келеді.
